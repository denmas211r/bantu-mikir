# MIM Inventory Analyst Web
Web statis (GitHub Pages) untuk proses kerja MIM Zona 1. Versi awal memakai DATA DUMMY.
Jalankan lokal: `python3 -m http.server 8000` lalu buka http://localhost:8000
Buat ulang data dummy: `node tools/init-data.js` (ganti password dulu di file itu).
Detail rencana: lihat SPEC.md dan CLAUDE.md.
